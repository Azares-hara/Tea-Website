# Tea-Website
A tea website for the Tea Cafe in Shillong


## Running Locally
1. Clone or download this repository
2. Open `index.html` in any modern browser — no build step or server needed
3. (Optional) Using VS Code's Live Server extension for auto-reload during edits

## Responsive Breakpoints
- **≥1024px** — full desktop layout, 3-column menu grid
- **≤900px** — tablet layout, mobile slide-in menu, stacked sections
- **≤640px** — mobile layout, single-column menu, touch-friendly slider

## What I Learned
- Building responsive layouts with Flexbox and CSS media queries
- Managing application state with vanilla JavaScript
- Consuming a REST API with `fetch()`, `async/await`, and JSON
- Handling form validation, loading states, and success/error feedback
- Debugging network requests with browser DevTools
